#  Angela's Photography Portfolio

Welcome to my photography portfolio website! This project showcases my passion for photography through a clean, responsive website built using only **HTML** and **CSS**.

##  About the Project

This website was created to display my photography, introduce myself, and provide visitors with a simple and enjoyable browsing experience. It features a modern layout with a hero section, an about page, a gallery, and contact information.

##  Features

- Responsive navigation bar
- Hero banner with call-to-action button
- Personal biography and introduction
- Photography gallery
- Clean and modern design
- Footer with contact information
- Built entirely with HTML and CSS

##  Technologies Used

- HTML5
- CSS3
